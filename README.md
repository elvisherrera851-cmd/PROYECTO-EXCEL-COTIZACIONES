  # Gestión de Clientes y Cotizaciones en Excel  
Proyecto práctico desarrollado en Excel para la gestión y seguimiento de clientes y cotizaciones comerciales.
El sistema está diseñado a partir de un flujo real de atención por WhatsApp y permite registrar múltiples cotizaciones por cliente, consultar el historial y visualizar de forma clara el estado de cada cotización.
## Funcionalidades
- Base de datos estructurada mediante Tablas de Excel  
- Soporte para múltiples cotizaciones por cliente (una fila por cotización)  
- Búsqueda de clientes y cotizaciones por número de teléfono  
- Visualización automática de la cotización más reciente  
- Estados de cotización controlados mediante validación de datos  
- Columna de comentarios para seguimiento de negociaciones  
- Formato condicional para identificación visual del estado  
- Protección de hojas y fórmulas para evitar modificaciones accidentales  
## Objetivo
Proporcionar una solución sencilla, funcional y escalable para pequeñas operaciones comerciales que necesitan controlar sus cotizaciones y el seguimiento de clientes utilizando Excel.
## Herramientas utilizadas
- Microsoft Excel (Tablas, BUSCARX, validación de datos, formato condicional)
